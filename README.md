# 🌾 Integrated Farming Prediction System

## 📌 Project Overview
The **Integrated Farming Prediction System** is an AI-based application designed to help farmers make better farming decisions using Machine Learning and Deep Learning techniques. The system provides useful predictions and recommendations related to crops, crop yield, market prices, fertilizers, crop diseases, and weather conditions.

The main aim of this project is to support smart farming, improve agricultural productivity, and help farmers make informed decisions.

## 🎯 Objectives

The project consists of six main modules:

1. **Crop Recommendation:** Recommends suitable crops based on soil nutrients and environmental conditions such as temperature, humidity, pH, and rainfall.
2. **Crop Yield Prediction:** Predicts crop yield based on relevant agricultural parameters.
3. **Crop Price Prediction:** Estimates crop prices using historical price data.
4. **Fertilizer Recommendation:** Suggests suitable fertilizers based on crop and nutrient requirements.
5. **Crop Disease Detection:** Identifies possible crop diseases from leaf images using Deep Learning.
6. **Weather Forecasting:** Provides weather information to help farmers plan agricultural activities.
